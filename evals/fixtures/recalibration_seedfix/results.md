# AgentGauge seed-fix re-calibration: old vs new corpus

Generated by `scripts/recalibration_analyze.py`. Bootstrap seed 42.

## Method

- Cluster bootstrap over TOOL SETS: B=2000, resample tool sets with replacement (random.Random(42)), recompute each statistic from per-tool-set sufficient statistics, percentile 95% CI (linear interpolation). Old-restricted and NEW share the same resamples so the new-minus-old difference CI is paired. rho resamples the 5 Phase-3 pairs (5 clusters; crude).
- ICC, nested variance shares, zero-variance share and rho are computed by the code of scripts/v2_variance_structure.py (imported) on constraint_satisfaction. Constants use joint_success: baseline = trial-weighted mean; sigma_task = population SD of group means; resid_sd = sqrt(mean population variance over groups with n>=2); rho = pooled Pearson of before/after group means over the 5 PHASE3 pairs.
- gold = (tool_set, task_tool_name) like the old analysis; true = (tool_set, task_description), NEW data only (old rows carry no description).
- Null: per tool set, bootstrap-resample each gold-tool trial pool twice (before/after), diff_server_level(threshold=0.05, CUPED); seed from a hash of the tool-set name. Eligible = >=2 gold tools each with >=2 trials.
- simulate_mde_task_level, power 0.8, trials_per_task=1, seed 42; constants rounded to 4 dp (rho 3 dp) as in harness.
